# Phase 3: 任务拆分 (DAG + Kahn拓扑排序)

> **门控**: G4 (Task Plan Gate) — DAG无环且可执行 → 通过
> **Layer**: Layer 3 → Layer 2
> **适用模式**: Strict（必跑）, Standard（条件执行）, Fast/Lean（跳过）
> **前置产物**: `03-tasks.md`

---

## 📋 DAG构建 + Kahn拓扑排序

1. **DAG构建**: 基于设计文档，拆分成原子任务，建立依赖关系
2. **Kahn拓扑排序**: 输出无环执行序列
3. **Wave分配**: 依赖组 → 同一Wave；独立任务 → 不同Wave可并行

---

## ⚡ v3.2 交互流程

**第1步：展示 Wave 计划（让用户快速确认）**

```
=== Phase 3: 任务拆分 ===

共拆分为 3 个 Wave，12 个任务：

Wave 1: 基础建设 (3任务, 预计 15分钟)
├─ [P0] T1: 初始化项目结构          无依赖 → 立即执行
├─ [P0] T2: 配置路由 + 导航         无依赖 → 立即执行
└─ [P1] T3: 封装 HTTP 请求客户端    依赖 T1

Wave 2: 核心功能 (5任务, 预计 45分钟)
├─ [P1] T4: 实现用户登录页面        依赖 T1, T2
├─ [P1] T5: 实现 Token 管理模块     依赖 T3
└─ [P2] T6: 实现仪表盘数据展示      依赖 T4, T5

Wave 3: 完善优化 (4任务, 预计 30分钟)
├─ [P2] T7: 用户管理页面            依赖 T4
└─ [P2] T8: 权限控制 + 路由守卫     依赖 T4, T5

预期总耗时: ~90分钟 | 总风险等级: 中
```

**第2步：用户确认或修改**

```
请确认 Wave 计划：

  [A] 确认执行 — 按此计划执行所有 Wave
  [B] 修改计划（指定要调整的内容）
  [C] 合并 Wave（将多个 Wave 合并）
  [D] 拆分 Wave（将大 Wave 拆为多个）
  [E] 跳过（直接执行 Phase 4）

  或输入自定义指令：

  注意：合并/拆分后需要重新评估耗时，确认 [A] 即开始执行 Wave 1。
```

**目标**: 每个任务原子化、可执行、有明确依赖关系。
