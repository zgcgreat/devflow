## 更新协议

Phase 2a 设计枪战用户选择后，自动更新此文件：

```yaml
update_rules:
  trigger: 用户选择设计变体后
  actions:
    - 记录选择到历史选择记录表
    - 更新 UI 风格偏好（从选中变体提取）
    - 更新组件偏好（从选中变体提取）
    - 更新调性倾向（从选中变体的 Style Direction 提取）
    - 如果连续 3 次选择同调性 → 设为首选调性
    - 如果连续 2 次拒绝同调性 → 加入排斥调性
```
